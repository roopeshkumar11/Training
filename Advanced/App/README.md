# React Native Learning Hub

A single React Native project to practice multiple topics in one place.

## Run the App

```bash
npm install
npx react-native run-android
```

## Current Topics

- **Offline-First Architecture (Notes App)** — `src/topics/OfflineFirst/OfflineNotesApp.tsx`

## Add a New Topic

1. Create your screen in `src/topics/<TopicName>/`
2. Add it to `TOPICS` in `src/topics/index.ts`
